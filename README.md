# Stillwater

A quiet place to wander: an original interactive blue-hour lotus pond built with Three.js, TypeScript, and Vite.

## Run locally

Requires Node.js 22.12+ (or a recent supported LTS) and npm.

```sh
npm ci
npm run dev
```

Open the local URL printed by Vite. Everything is rendered locally; no account, backend, CDN, analytics, or external assets are required.

## Explore

- **Enter the pond** to begin.
- **WASD / arrow keys:** glide above the water.
- **Mouse direction:** move toward the top/bottom to glide forward/backward and left/right to turn. The centre is a quiet zone to slow to a stop; farther from centre moves faster. No click or hold is required, and hovering a nearby flower/lantern or moving onto controls pauses navigation. Click-drag look remains available.
- **Nearby lotuses:** gently open on approach; hover to open further.
- **Lanterns:** warm on approach and blush red on hover or tap; some float on the water, others drift above it.
- **Water:** moving the mouse over the pond leaves spreading wave rings and a fading wake, bending reflections locally. No click is needed; Motion/Still mode freezes the waves.
- **Sky:** a rich, gently twinkling star field above the blue-hour mountain horizon (2,400 stars on desktop, 1,200 in touch/low-quality mode).
- **Touch:** drag to look, arrow controls to glide, and tap nearby objects.
- **Sound:** optional synthesized quiet water/wind, off until you enable it. Automatically turns off when the tab is hidden.
- **Motion:** freeze ambient motion. Respects the operating system's reduced-motion preference; intentional navigation remains available.
- **Reset view / guide:** in the bottom-right controls.

## Verify

```sh
npm run check
npm run build
npx playwright install chromium
npm run test:e2e
```

Unit tests cover navigation, proximity response, world animation/resources, and audio lifecycle. Playwright exercises real WebGL rendering in Chromium (SwiftShader for headless machines), desktop and touch controls, reduced motion, and unsupported graphics.

## Production

```sh
npm run build
npm run preview
```

`dist/` is a static site. Host it with HTTPS on a static host of your choice. The repository is private; no public deployment is enabled automatically. `?test=1` exposes a read-only scene snapshot for automated tests; it contains only scene state, not personal data.

## Design and constraints

Procedural lotus petals and leaves, paper lanterns, layered karst-inspired mountains, hovering cloud wisps, atmospheric mist, and animated water. Water uses a quality-scaled planar reflection pass with shader ripples. Lotus petals physically unfold using morph targets. The mountains use original layered jade-and-ink shader washes. Rendering scales down on touch devices. Camera stays above the pond and within its navigable boundary. All artwork and sound are generated by the project.
